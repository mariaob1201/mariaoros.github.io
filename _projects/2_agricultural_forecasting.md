An LLM-based advisory system that helps growers reason about crop disease risk. The natural-language front end is backed by ML models that forecast risk from real-time [Wisconet](https://wisconet.wisc.edu/) weather station data, so growers can ask questions in plain language and get model-grounded recommendations for spraying decisions.

- **Live app:** [connect.doit.wisc.edu/ag_forecasting](https://connect.doit.wisc.edu/ag_forecasting/)
- **Source code:** [UW-Madison-DSI/ag_forecasting_app_v3](https://github.com/UW-Madison-DSI/ag_forecasting_app_v3)
